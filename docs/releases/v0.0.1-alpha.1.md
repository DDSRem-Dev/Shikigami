# Shikigami v0.0.1-alpha.1

首个公开 alpha，供开发和隔离环境试用。Phase 0–5 的完整交付验收尚未完成，不承诺生产稳定性或完整平台兼容性。

## 已实现的功能

- CLI/TUI、本地常驻 agent、远端 daemon，以及通过受认证的 HTTP/2 连接使用 tmux 终端会话。
- 项目级双向文件同步：共同基线、条件提交、冲突保留和显式解决。
- 双端独立 sync/port 插件；默认绑定本地 loopback 的 TCP 转发、半关闭和恢复。
- 会话配置快照、状态与日志诊断、固定版本安装、升级回滚和保留数据卸载。

## 产物与信任

提供 Linux/macOS 的 amd64、arm64 四目标归档。每份归档均附 SHA-256 摘要、checksums pin、Ed25519 签名和验签回执；发布流程在签名及验签成功后才公开 Release。

签名公钥位于仓库 `configs/release-signing.pub`。预先确认的 SPKI DER SHA-256 指纹：

```text
e21f6dd671ea5042c43c492b759b933dda73985f89a823b43c651ff7c787c17d
```

先从可信仓库取得 verifier 和公钥，使用固定版本、OS、arch 验签，再从认证副本解包并运行安装器。不能仅信任下载包旁附带的公钥或摘要。完整步骤见仓库 `docs/11-automated-installation.md`；实际发布提交和运行编号由本次自动发布记录提供。

## 验收边界

源码的 Ubuntu/macOS CI、四目标打包和签名验签属于自动检查范围。首发前92cafaf源签名候选已通过本机macOS arm64与Linux arm64容器的真实新装、运行及开发版本升级回滚，使用目标包自身安装器并核验清理。自动发布将从tag重新构建；这些证据不表示两次归档字节相同，详情及来源边界见 `docs/18-release-readiness.md`。

以下仍未完成：真实 Tailscale/Claude 账号与官方控制面生命周期、实际 P2P/DERP、物理多设备、原生 VPS/重启登录持久化、原生 Intel/amd64 与 WSL 完整兼容性，以及当前候选的完整长期资源稳定性。交叉编译、翻译执行和容器测试不替代这些门槛。

首版之前没有正式发行版本；开发候选之间的升级回滚不代表历史正式版本迁移已经验收。现有配置、认证状态和项目数据需要独立备份；回滚二进制不会还原项目文件、Claude 对话或已撤销的凭据。

GUI、WSS、增量同步、文件快照、终端历史回放及多租户未在本版提供。归档签名不等同 Apple 应用代码签名或公证；Homebrew 分发尚未提供。

## 问题反馈

通过 [GitHub Issues](https://github.com/DDSRem-Dev/Shikigami/issues) 提交版本、OS/arch、复现步骤、退出码及脱敏的 reason_code；这是公开问题反馈入口，没有承诺响应时限。故障排除与恢复步骤见仓库 `docs/18-release-readiness.md`。请勿附带 Token、密钥、登录 URL、私有配置或项目内容。MIT 许可证包含在归档中。

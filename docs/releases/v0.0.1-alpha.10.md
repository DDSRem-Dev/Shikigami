# Shikigami v0.0.1-alpha.10 — 发布草案

本文件是待批准的发布草案，当前公开版本仍是 alpha.9。本候选用于远程浏览器滚动与弱网体验的下一轮实测，不是 beta 或稳定版。源码检查通过不等于已发布、已升级或已解决现场卡顿。

## 改进

- 新查看器默认使用 **Smooth**，降低图像质量并增加压缩；仍可选择 Balanced 或 Clear。画质设置不改变远端分辨率或控制权限。alpha.9 的同页动画对照显示 Smooth 有助于缩短响应，但滚动连贯性仍需实测。
- noVNC 固定升级到官方 1.7.0，纳入图像绘制后的资源释放、JPEG 扫描优化及视频解码能力探测的资源关闭。补充图像顺序、释放时机和传输分片回归。

## 升级与复验

本版本资产尚未发布，不要提前执行对应版本的下载命令。批准发行并完成签名流水线后，Mac、VPS 应用与 VPS 受管浏览器 runtime 需一起升级。

升级前保存远端 Chrome 中未提交的内容；系统支持更新需要显式停止受管 Chrome。原有节点身份、连接配置、项目、浏览器 profile 和密钥环应保留，实际升级后逐项复核。关闭查看器不等于停止 Chrome。

升级后打开可控制查看器须明确指定：

```bash
shiki --server my-vps browser open work --read-only=false --launch
```

在查看器点击 **Take control**，等到显示 **Controller** 后操作。默认只读链接不能直接取得控制。使用 Smooth 对比滚动、点击与输入；测试时暂停网页背景视频，并把调整远端分辨率作为单独对照，避免同时改变多个条件。

## 验证范围

本地通过查看器28项行为测试、51个Fence解析/转发子例，以及browser client/server与架构race检查。测试明确覆盖异步图像顺序、资源释放及跨块字节保真，不将mock Image/canvas当作真实浏览器GC或帧率验收。完整候选CI以Actions对应源码记录为准；隔离网络库升级的测试不属于本版生产范围。

用户在正式 alpha.9 上选择 Smooth 并暂停 Claude 登录页背景视频后，已反馈整体操作可用，但滚动仍有低帧率感；这不是本候选部署结果。5 Mbps 套餐、实际链路吞吐、画面变化量和丢包都可能影响体验，本版不承诺固定帧率。真实两端升级/回滚、原网络滚动体验、自然断线恢复、长期使用及 Claude 账号授权分别保留验收门槛。

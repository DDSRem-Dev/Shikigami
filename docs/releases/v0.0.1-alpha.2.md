# Shikigami v0.0.1-alpha.2

**历史发行范围：** 以下验收状态描述该版本发布时的事实，不作为当前待办清单。当前进度见[路线图](../08-roadmap.md)；真实Claude登录/推理已按用户要求移出当前交付验收且未实测，见[11验收范围](../11-automated-installation.md#claude-acceptance-scope-20261031)。

本版增加自动 Homebrew 分发，并将本项目许可证改为 GPL-3.0-only。仍是供开发与隔离环境试用的 alpha，完整 Phase 0–5 验收尚未完成。

## 本版变化

- 公开 Release 通过签名和完整资产核验后，工作流自动生成并提交 Homebrew Formula；后续版本只需推送 tag，无需手改版本、URL、摘要或许可证。
- Formula 安装时验证 Ed25519 签名、归档、校验清单与全部成员，保留双端插件及 manifest；包安装与服务激活分开，升级和卸载不会隐式修改用户状态。
- 根目录及本版归档采用完整 GPL-3.0-only 许可证。历史 v0.0.1-alpha.1 仍保留其发布时的 MIT 许可证。
- 完成原 Linux 12 小时运行的全部 5,920 条资源记录分析，以及隔离临时密钥的轮换／撤信演练。没有因 RSS 波动修改生产实现。

## Homebrew

本版 Release 公开之后，自动工作流会在仓库 master 创建或更新 Formula；以整个 Release 工作流成功为分发完成条件。

```bash
brew tap ddsrem-dev/shikigami https://github.com/DDSRem-Dev/Shikigami
brew install ddsrem-dev/shikigami/shikigami
```

`brew install` 只安装已认证的完整 bundle。服务激活、登录和受管安装升级仍需按 caveats 及 `docs/22-homebrew-distribution.md` 显式执行。已有稳定版后，预发布不会替换稳定渠道；旧 tag 运行不会使 Formula 回退。

本机 macOS 27 的 Homebrew 完整安装因现有 Xcode/CLT 版本不足被前置拒绝；公式本身与隔离容器的验收范围单独记录，不能用它们冒充本机 brew 全流程成功。完整验证结果见工作流及后续 `docs/15-implementation-status.md`。

## 验收边界

原697文件源码的Linux默认12小时凭据自然轮换、恢复尾部和清理通过，不代表本版完整长稳或无内存泄漏。隔离签名演练没有操作实际发行密钥；当前 verifier 无在线撤销或可信签名时间戳。

真实 Tailscale/Claude 账号、官方控制面生命周期、实际 P2P/DERP、物理多设备、原生 VPS/重启登录持久化、原生 Intel/amd64 与 WSL 完整兼容性，以及当前版本长期资源稳定性仍待验收。归档签名不等同 Apple 代码签名或公证。

升级前独立备份配置、身份状态和项目数据。二进制回滚不会恢复项目文件、Claude 对话或已撤销的凭据。故障排除及安装限制见 `docs/18-release-readiness.md`；通过 [GitHub Issues](https://github.com/DDSRem-Dev/Shikigami/issues) 反馈脱敏复现，无响应时限承诺。

# Shikigami v0.0.1-alpha.3

供用户在可恢复的测试环境中试用的预发行版，不是 beta 或稳定版。升级前备份配置、身份状态和项目数据；地区/DNS 系统变更应保留 SSH 或带外控制台恢复入口。

## 本版变化

- 新增可选 `region` 插件：JP/US 地区配置、时区/UTF-8 locale/语言格式、只读计划与显式应用、版本竞争检查和回滚。系统 DNS 单独授权，确认超时由独立恢复守卫处理；不修改 VPN、代理出口、路由或系统真实时钟。
- 新增可选 `browser` 插件：服务端官方 Chrome、持久 profile、独立 systemd 用户运行服务；客户端通过受保护的 loopback noVNC 查看器使用。支持显式单控制者接管、只读观察、中文/日文输入法、显式剪贴板和授权上传/下载。
- 新增管理员系统依赖安装/维护、整机 Chrome 托管策略和可选 systemd 加密凭据启动解锁。普通 daemon、插件和 Chrome 不以 root 运行；启用插件不会自动安装系统包。
- 诊断区分主机、目标 Chrome 与外部观察；外部探测默认关闭，未知结果不当作通过。不提供防封保证或伪造浏览器指纹。
- 包含 alpha.2 之后的安装恢复、第三方插件签名安装/生命周期、bootstrap、Homebrew 与发行资产一致性修复，以及本批上传终态、查看器下载 EOF、输入法和敏感状态目录保护修复。

## 安装与试用

提供 Linux/macOS × amd64/arm64 四目标归档及固定源码的 `bootstrap.sh`。归档可构建不等于每项新功能均已在该平台实测；浏览器服务端要求 Linux/systemd、官方 Chrome 及完整运行依赖，macOS 包只提供浏览器客户端，不安装地区 helper 或 Linux 浏览器运行服务。

先从独立可信来源取得仓库公钥/指纹，再验证固定版本、目标和完整归档。Ed25519 SPKI SHA-256：

```text
e21f6dd671ea5042c43c492b759b933dda73985f89a823b43c651ff7c787c17d
```

Homebrew Formula 由成功发布流程自动更新，不手改摘要。安装包与服务激活分开：

```sh
brew tap ddsrem-dev/shikigami https://github.com/DDSRem-Dev/Shikigami
brew install ddsrem-dev/shikigami/shikigami
```

已有安装先按维护文档检查布局和升级路径。地区/浏览器还需要管理员显式执行 `shiki-install setup`，审阅依赖、权限和 Chrome 策略后才确认。密钥环口令只通过 stdin 输入；不分享 Token、Cookie、口令或 profile。

完整步骤见本 tag 的 [安装文档](../11-automated-installation.md)和[地区/浏览器使用说明](../27-region-browser-plugins.md)。关闭查看器不停止远程 Chrome；停止浏览器与删除 profile 是不同操作。

## 风险与验收范围

新增功能已有隔离 Debian 12/Ubuntu 24.04 amd64 的分层行为、实际 systemd/Chrome/noVNC、中文/日文输入、文件传输、密钥环及签名安装证据。精确源码/产物与失败修复见[实施记录](../15-implementation-status.md)；历史不同快照不合并声称为同一发行包全矩阵通过。最终 CI、构建和签名结果以本版本关联的 GitHub Actions 运行及发行来源信息为准。

真实 Claude 人工授权、公网地区/信誉、物理主机重启，以及新增功能完整 ARM64/macOS/WSL2 原生体验仍需用户环境验证。旧功能平台验收和 CI 单元测试不能替代这些项目。

- Chrome 托管策略影响同机全部官方 Chrome：关闭密码保存、Chrome 同步和 Chrome 账号登录；网站登录仍可用。既有冲突策略拒绝覆盖。
- Cookie 保存在持久 profile，但不保证登录永久有效。Chrome 同 UID 文件选择器不是整机文件沙箱。
- 无 TPM 的 host-key 加密凭据不抵御整盘与 root 密钥同时失窃。解锁失败不会退回明文密钥存储。
- DNS 恢复可能因外部修改或系统故障失败；冲突必须人工复核，不可盲目重试或移除守卫。
- 二进制降级不回滚系统设置、项目文件或状态 schema；新 region journal 使用 schema 2，不能用旧 helper 推断事务归属。
- 归档签名不是 Apple 代码签名或公证。许可证为 GPL-3.0-only，第三方依赖保留各自许可证。

通过 [GitHub Issues](https://github.com/DDSRem-Dev/Shikigami/issues)提交脱敏步骤、系统/架构、版本和错误时间；无响应时限承诺。

# Shikigami v0.0.1-alpha.4

本版将首次部署收敛为 VPS 和 Mac 各一条命令，自动处理依赖、服务、连接引导和插件配置。仍为预发行版；账号授权及明确的系统变更确认需要用户完成。

## 一键安装

VPS（Debian 12 / Ubuntu 24.04，systemd）：

```bash
curl --proto '=https' --proto-redir '=https' -fsSL https://github.com/DDSRem-Dev/Shikigami/releases/download/v0.0.1-alpha.4/bootstrap.sh | sudo bash -s -- --quickstart --version=v0.0.1-alpha.4
```

Mac（当前登录用户，不加 sudo）：

```bash
curl --proto '=https' --proto-redir '=https' -fsSL https://github.com/DDSRem-Dev/Shikigami/releases/download/v0.0.1-alpha.4/bootstrap.sh | bash -s -- --quickstart --role=client --version=v0.0.1-alpha.4
```

先完成 VPS 向导，再在 Mac 输入向导提供的服务器地址和设备 Token。默认包含全部四种插件的支持；只需终端、同步和端口转发时，在两端命令末尾追加 `--components=core`。交互从终端读取，口令和 Token 隐藏输入。已有本版客户端可运行 `shiki setup`。

## 本版变化

- 受信 bootstrap 自动检测平台、验证发行签名，并将验证后的归档交给安装向导，无需手工下载公钥、拼接校验值或编辑 YAML。
- VPS 默认使用专用普通账号 `shiki`，安装 tmux、缺失的官方 Claude 和所选系统支持；Mac 安装 agent 并配置命令 PATH。
- 连续引导内嵌 Tailscale 登录、服务器配对、双端插件启用及就绪检查。Claude 尚未授权时可先配对并打开远程浏览器，应用就绪仍准确显示待完成。
- 同版本重复执行保留身份、配置和浏览器 profile，复用受信系统支持；失效设备 Token 经确认后换新，部分密钥环登记继续使用原加密 store。
- 原高级安装、维护和卸载入口保留。公开 alpha.3 不包含新向导，旧归档不修改。

## 插件与后续使用

| 插件 | 用途与入口 |
|---|---|
| `sync` | 项目文件双向同步。在本地项目目录运行 `shiki`，按提示创建/映射项目；首次差异和冲突需明确选择方向。 |
| `port` | 将获准的远端 TCP 端口转发到本机 loopback。向导可配置允许端口，完整替换既有配置前会确认；插件 ready 不代表已建立转发。 |
| `region` | Linux 服务端地区/时区/locale 管理。向导安装支持并启用插件，实际地区和 DNS 仍需用户审阅计划、显式应用。 |
| `browser` | Linux 服务端持久 Chrome 与 Mac 本地查看器。向导可创建或显式恢复 profile、启动并打开查看器；点击 Take control 后输入。关闭查看器不会停止远端 Chrome。 |

完整操作与恢复契约见[一键安装](https://github.com/DDSRem-Dev/Shikigami/blob/v0.0.1-alpha.4/docs/28-quickstart.md)、[插件使用说明](https://github.com/DDSRem-Dev/Shikigami/blob/v0.0.1-alpha.4/docs/27-region-browser-plugins.md)和[安装维护文档](https://github.com/DDSRem-Dev/Shikigami/blob/v0.0.1-alpha.4/docs/11-automated-installation.md)。

## 验证与边界

本地验证覆盖 bootstrap 的真实 HTTPS/Ed25519 测试、客户端实际 IPC 向导、安装器前台终端/Token/恢复测试、相关包 race、Linux arm64 隔离容器及 Linux amd64 入口交叉构建。完整 CI、四目标构建与签名结果以本版本关联 Actions 和 `PROVENANCE.json` 为准；本地与外部证据不混用。

真实 VPS/Mac 从零执行新向导、官方账号授权和物理重启恢复仍需实际环境验证。浏览器服务端依赖 Linux/systemd 和官方 Chrome；macOS 仅提供浏览器客户端。Chrome 托管策略影响同机全部官方 Chrome，关闭密码保存、Chrome 同步和 Chrome 账号登录，网站登录仍可用。无 TPM 的 host-key 加密凭据不抵御 root 或整盘连同密钥失窃。

不会自动选择整机国家、DNS、网络出口或同步冲突方向。中断安装事务、未提交密文及外部修改冲突仍可能需要显式恢复；安装系统依赖不是可完整回滚的大事务。保留 SSH 恢复入口，升级前备份配置和数据。

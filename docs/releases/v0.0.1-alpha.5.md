# Shikigami v0.0.1-alpha.5

修复 alpha.4 实际安装中遇到的确认输入阻塞、静默长操作和普通用户无法执行浏览器支持程序的问题。已有 alpha.4 半安装状态可以重新执行本版向导继续，不需要手动 chmod 或删除密钥环。

## 一键安装或继续安装

VPS（Debian 12 / Ubuntu 24.04，systemd；root 或具备 sudo 权限的管理员）：

```bash
curl --proto '=https' --proto-redir '=https' -fsSL https://github.com/DDSRem-Dev/Shikigami/releases/download/v0.0.1-alpha.5/bootstrap.sh | sudo bash -s -- --quickstart --version=v0.0.1-alpha.5
```

Mac（当前登录用户，不加 sudo）：

```bash
curl --proto '=https' --proto-redir '=https' -fsSL https://github.com/DDSRem-Dev/Shikigami/releases/download/v0.0.1-alpha.5/bootstrap.sh | bash -s -- --quickstart --role=client --version=v0.0.1-alpha.5
```

默认安装全部插件支持。向导仍需确认系统变更、设置密钥环口令并完成账号授权；一键执行不代替这些选择。之前密钥环登记中断时使用原口令，已有密钥环不会重置。

## 修复

- 修正终端读取在 sudo 分配的 PTY 中无法推进确认输入的问题，并处理 macOS `/dev/tty` 的就绪检测差异。
- 验签、系统依赖、Chrome、语言包与服务配置显示当前步骤、完成/失败和耗时。长操作每10秒提示仍在运行，不以虚假的百分比表示进度；口令输入期间不刷新进度。
- 在严格 `umask 077` 下正确创建公共程序和配置目录；继续安装时修复已知公共目录，保持 root 所有和普通用户不可写。凭据目录与秘密文件保持私有，不递归放宽权限。
- 密钥环口令提示说明用途与隐藏输入行为。登记服务失败时附带受限的 systemd 状态和对应日志命令，不输出密码或子进程秘密内容。

完整流程与四种插件说明见[一键安装](https://github.com/DDSRem-Dev/Shikigami/blob/v0.0.1-alpha.5/docs/28-quickstart.md)及[插件文档](https://github.com/DDSRem-Dev/Shikigami/blob/v0.0.1-alpha.5/docs/27-region-browser-plugins.md)。

## 验证边界

本版关联 Actions 和 `PROVENANCE.json` 记录固定源检查及四目标签名构建。源码回归和隔离环境证据见08/15/16，不代表用户 VPS 完整首装、真实账号授权或物理重启已经通过。alpha.4 公开标签与资产不修改。

仍为预发布版本。Linux 浏览器使用官方 Chrome 和加密密钥环；macOS 提供客户端。整机 Chrome 策略禁用密码保存、Chrome 同步及 Chrome 账号登录，网站登录仍可用。host-key 加密不抵御 root 或整盘连同密钥失窃。不会自动选择地区、DNS、网络出口或同步冲突方向。许可证 GPL-3.0-only。

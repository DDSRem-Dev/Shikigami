# Shikigami v0.0.1-alpha.6

集中修复 alpha.4–alpha.5 安装、配对和远程浏览器使用反馈，保留已有配置、凭据、项目与浏览器数据。

## 一键安装或升级

VPS（Debian 12 / Ubuntu 24.04，systemd）：

```bash
curl --proto '=https' --proto-redir '=https' -fsSL https://github.com/DDSRem-Dev/Shikigami/releases/download/v0.0.1-alpha.6/bootstrap.sh | sudo bash -s -- --quickstart --version=v0.0.1-alpha.6
```

Mac（当前登录用户，不加 sudo）：

```bash
curl --proto '=https' --proto-redir '=https' -fsSL https://github.com/DDSRem-Dev/Shikigami/releases/download/v0.0.1-alpha.6/bootstrap.sh | bash -s -- --quickstart --role=client --version=v0.0.1-alpha.6
```

向导复用已保存的节点身份、服务器凭据及密钥环登记。系统变更仍需确认，账号授权仍由用户完成。已有运行中的受管 Chrome 如需更新支持程序，先按提示停止浏览器，再重跑向导；profile 保留。

## 修复

- 确认统一支持 y/yes/n/no；服务器标签、地址和端口分别说明，错误地址原地纠正，已有地址可显式修改且保留身份 pin。
- Token 提示说明隐藏输入、Enter 提交和 Ctrl+C 取消；提交后显示连接验证阶段。延续 alpha.5 的阶段耗时提示和控制终端修复。
- 快速安装经批准仅移除所选 home 的组/其他用户写权限，修复 worker 信任路径失败；受保护 shell 文件保留并准确报告。
- 显式 region 安装为受管 daemon 配置既有受限 sudo helper 所需的服务策略，避免插件启动失败；仅在必要时重启 daemon，core-only 安装保持原限制。
- 已接受的插件配置修改遇到瞬时网络错误时，只重试状态查询，保留 revision 和原截止时间，不重放修改。
- 短暂探测超时不立即终止仍有进展的共享连接；重叠调用可以共用同一次成功身份检查，后续独立调用继续验证身份。
- 控制面暂时离线不自动重新登录或要求更换应用 Token；启动失败提示指出发生在哪个阶段。
- 查看器增加显式画面重连，隔离旧连接的延迟回调，状态与画面并行启动。重新连接从只读开始，显示 Controller 后才可输入，不重放鼠标或键盘操作。
- 修复 macOS 大小写不敏感文件系统上本地 socket 临时名冲突，并补充节点启动注册与一次性密钥登录回归。

完整问题清单见[安装修复记录](https://github.com/DDSRem-Dev/Shikigami/blob/v0.0.1-alpha.6/docs/29-alpha6-installation-followup.md)，安装和插件说明见[使用指南](https://github.com/DDSRem-Dev/Shikigami/blob/v0.0.1-alpha.6/docs/28-quickstart.md)。

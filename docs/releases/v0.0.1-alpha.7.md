# Shikigami v0.0.1-alpha.7

候选说明：尚未发布，以下安装命令仅供发布后使用。

修复 alpha.6 发布后验收发现的浏览器快速重连竞态，保留已有配置、节点身份、凭据、项目和浏览器 profile。是否已公开发布以 GitHub Release 为准；当前安装入口见[安装指南](https://github.com/DDSRem-Dev/Shikigami/blob/master/docs/28-quickstart.md)。

## 修复

- WebSocket 关闭确认后，等待旧连接的本地 SDK Close 返回、socket 清理和双向数据处理退出，再允许新画面连接。避免偶发拒绝重连或过早开启第二条远端流；此本地清理屏障不代表远端释放确认。
- 最多一个重连请求等待，额外请求明确拒绝。等待与远端握手共享原有操作预算，不取消仍活动的连接，不自动取得控制权，也不重放输入。
- 修复 macOS 验收夹具枚举短命子进程的退出竞态。仅独立确认进程消失才跳过，权限和未知错误仍失败。

## 安装或升级

VPS：

```bash
curl --proto '=https' --proto-redir '=https' -fsSL https://github.com/DDSRem-Dev/Shikigami/releases/download/v0.0.1-alpha.7/bootstrap.sh | sudo bash -s -- --quickstart --version=v0.0.1-alpha.7
```

Mac（当前登录用户，不加 sudo）：

```bash
curl --proto '=https' --proto-redir '=https' -fsSL https://github.com/DDSRem-Dev/Shikigami/releases/download/v0.0.1-alpha.7/bootstrap.sh | bash -s -- --quickstart --role=client --version=v0.0.1-alpha.7
```

浏览器系统支持程序升级如要求停止正在运行的受管 Chrome，先保存网页内容并按提示停止；profile 保留，升级后显式恢复。既有身份和密钥环登记复用。

## 验证边界

确定性真实 loopback 回归覆盖旧 attachment 清理阻塞、原预算超时、单等待者、取消隔离和只读新连接；客户端 race 与前端行为测试通过。固定源 CI 和发行来源见 Actions 与 PROVENANCE.json。发布前的本地验证不等同于两端部署后的鼠标操作、公网长期稳定、真实 Claude 登录或物理重启验收。旧版标签和签名资产不覆盖，许可证 GPL-3.0-only。
